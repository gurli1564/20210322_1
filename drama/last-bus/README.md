# 마지막 버스 (1분 로맨스 쇼츠)

## 기획
- **장르**: 로맨스 (설렘 / 반전)
- **길이**: 60초, 8컷
- **화면비**: 9:16 세로 (쇼츠·릴스용)
- **로그라인**: 비 오는 밤 버스정류장. 한 달째 자기 버스를 그냥 보내던 남자. 그걸 다 보고 있던 여자에게도 비밀이 있었다.

## 등장인물
| 이름 | 나이 | 설정 |
|---|---|---|
| **지은** | 27 | 회사원. 침착하고 장난기 있음. 매일 밤 같은 정류장에서 버스를 기다림 |
| **도윤** | 28 | 회사원. 수줍음 많음. 지은이 혼자 기다리는 게 신경 쓰여 한 달째 7번 버스를 놓치는 중 |

## 대본

**S#1. 버스정류장 / 비 오는 밤**

| 컷 | 시간 | 화면 | 대사 / 소리 |
|---|---|---|---|
| C1 | 0–6초 | 비 내리는 정류장 와이드. 지은이 좁은 지붕 아래 젖은 채로 서 있다 | (빗소리, 잔잔한 피아노 시작) |
| C2 | 6–12초 | 도윤이 뛰어 들어와 우산을 접는다. 지은을 힐끗 보고 시선을 피한다 | (발소리, 우산 터는 소리) |
| C3 | 12–20초 | 7번 버스가 도착해 문이 열린다. 도윤은 타지 않는다. 버스가 떠난다. 지은이 그걸 본다 | (버스 브레이크, 문 열리고 닫히는 소리) |
| C4 | 20–28초 | 지은이 도윤 쪽을 돌아본다 | **지은**: 또 안 타요?<br>**도윤**: (놀라며) …보셨어요? |
| C5 | 28–38초 | 지은 미디엄 샷 → 도윤 리액션 | **지은**: 한 달째잖아요. 7번 그냥 보내는 거.<br>**도윤**: (머쓱하게 웃으며) 비 오는데… 혼자 기다리시는 게 좀 그래서요. |
| C6 | 38–46초 | 지은 클로즈업. 살짝 웃는다 | **지은**: 제 버스, 사실 아까 지나갔어요. |
| C7 | 46–54초 | 도윤이 멍하니 보다가 웃음이 터진다. 우산을 펴서 지은 쪽으로 기울인다. 도윤 어깨가 젖는다 | **도윤**: …그럼 걸어갈까요?<br>(피아노 고조) |
| C8 | 54–60초 | 뒷모습 와이드. 우산 하나를 같이 쓰고 빗속을 걸어간다. 타이틀 "마지막 버스" | (빗소리, 음악 마무리) |

## 사운드
- **BGM**: 잔잔한 솔로 피아노, 70~80 BPM. C7에서 현악이 살짝 들어오며 고조
- **효과음**: 빗소리 깔기, 버스 브레이크와 문 소리, 우산 펴는 소리
- **음성(TTS)**: 지은은 차분하고 살짝 장난스러운 20대 여성 톤, 도윤은 낮고 부드러운 20대 남성 톤. 속삭이듯 작게

## 제작 순서
1. `prompts.md`의 캐릭터 시트로 인물 기준 이미지를 먼저 만든다 (이미지 AI)
2. 그 이미지를 참고 이미지로 넣고 컷별 프롬프트로 영상을 생성한다 (영상 AI, 컷당 5~10초)
3. 대사를 TTS로 만들거나 직접 녹음한다
4. CapCut이나 Premiere에서 컷을 이어붙이고 BGM과 자막을 넣는다
